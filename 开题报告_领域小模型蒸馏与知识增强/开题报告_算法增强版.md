# 面向合金配方辅助设计的分约束效用选样与小模型蒸馏方法研究

## 1 选题背景及选题意义

### 1.1 选题背景

合金配方方案的准备需要把设计要求、允许元素、比例范围和已有研究记录联系起来。研究者不仅要找到相近配方，还要区分测试条件、保留指定成分、修改候选并整理依据。语言模型提供了以自然语言组织这些操作的途径：LLMatDesign 展示了根据指令修改材料并调用工具评价的辅助设计范式[1]；针对 BCC/B2 合金的研究表明，开源模型经过任务适配能够提出目标类别的成分候选[2]。LLaMat 与 AlloyGPT 则分别从领域适配和结构化生成角度说明材料信息可以与语言模型结合[3][4]。

这些进展尚不能直接转化为不经复核的材料设计结论。候选生成可能忽略锁定项、混用比例单位、错配条件或给出无依据的性能数值；相近成分在另一状态下的观测也不能直接证明新配方达到目标。对方案准备而言，更合适的系统应执行明确约束、保留记录来源，并将观测值、估计值和待验证建议分别标注。它提供可复核的候选，不替代材料实验和领域判断。

本地小模型为这一场景提供了可研究的部署方式。模型与检索资料可以保存在本地，版本可固定，内部配方无需为完成一次任务而发送到外部接口。但本地部署本身不保证效果、成本优势或数据安全：小模型仍须学习任务行为，资料使用权限及工具联网也需要核验。因此，本课题把本地化作为应用条件，将主要计算机方法问题放在“有限教学预算下，小模型应学习哪些可靠示范”。

现有数据选择已经研究质量、难度、多样性和梯度效用[12][13][14][15]。需要进一步区分的是，学生当前容易出错的样本不一定具有较高训练价值；一个样本对某类要求有帮助，也可能对另一类要求产生副作用。若先把不同约束表现压缩成一个总分，就可能掩盖这种取舍。这里的副作用是本课题拟检验的假设，不能从成分约束存在数学耦合，直接推出模型训练梯度必然冲突。

### 1.2 研究目标与任务定位

本课题拟构建可本地运行的合金配方辅助原型，以序列级任务蒸馏和知识增强为基础，研究分约束效用驱动的教学组合选择方法。目标是在限定数据、模型容量与训练预算下，检验可靠诊断信号能否帮助选出更有效的教学子集，并改善约束执行和记录对应质量。与指定教师的差距作为比较维度，不预设必须接近或超过某个通用大模型。

主要任务是“有记录依据的候选提出”，辅助任务是“给定配方按要求修改”。输入包括自然语言要求、允许元素、比例限制、可选原配方和必要条件；输出包括候选成分、操作说明、来源标识及检查结果。例如，用户要求降低某元素、保持另一元素不变且不新增元素，系统应按明确数值限制提出修改方案；对“更便宜”等尚无数值的偏好，保留偏好或请求补充，不能擅自设置具体上限。

记录支持型候选须对应可追溯记录及适用条件。新成分若缺少对应观测，只作为待验证编辑建议，不继承原配方或相近配方的性能数值。两类结果分开评价，数值合法不等于材料性能达标。本课题不生成完整晶体坐标，不联合优化通用工艺路线，不以预测新合金真实高温性能作为完成前提。

### 1.3 选题意义

**应用意义在于降低方案准备的操作负担。** AlloyLens 的专家参与案例表明，交互筛选、局部敏感性分析和多目标取舍具有实际应用背景[5]。本课题拟辅助整理候选、执行成分限制和回溯记录，预期减少重复查证与修改。该收益需要通过任务质量、修正量和有限案例验证，不由界面演示或模型生成速度直接推定，更不预先承诺缩短全部研发周期。

**方法意义在于把“难”与“值得学”分开。** ROSE 已用偏好代理服务于选样，DRIFT 进一步利用当前模型回答的正确性构造效用目标[16][17]。本课题在这些研究基础上，保留教学样本对不同约束组的影响向量，研究在预算内改善薄弱组、同时限制其他组预测损失上升的组合选择。改进的价值由共享诊断信息下的强对照支持，不以增加评分项或复杂求解器作为创新证明。

**证据意义在于让模型学习与输出复核保持一致。** 教师可以提供操作示范，材料事实仍来自记录和适用工具。教学准入、诊断标签与推理引用共用成分、条件、来源和约束状态，有助于明确哪些结论可检查、哪些尚缺依据。蒸馏并非把教师回答当真值，而是学习经过核验的任务执行方式；检索补充资料，数值程序承担可确定计算。

**部署意义在于形成可保存和可复用的领域能力。** 本地权重、资料快照与工具版本可以固定，并在相同环境中重用。该优势不依赖模型一定超过云端服务，但也不能代替可用性检验。研究将分别记录训练摊销、设备与调用成本，不预设本地总比低价 API 便宜。方法若有效，可为相近的多约束辅助生成任务提供研究思路；本课题不将未验证的跨领域迁移写成既有成果。

## 2 文献综述

### 2.1 材料语言模型与受约束辅助生成

LLMatDesign 将语言理解、材料修改和工具评价组成迭代流程[1]。BCC/B2 合金生成工作使用开源模型与物理反馈进行偏好适配[2]，说明本地模型生成合金候选已有直接前作。其公开代码、成分资源与受许可限制的偏好计算数据应分别看待，不能概括为完全不可复现，也不能将开源软件可安装等同于奖励适用。

LLaMat 研究大规模领域适配[3]，AlloyGPT 将组成与性质组织为结构化文本进行预测与设计[4]。二者支持领域模型研究，但其数据规模与计算条件不能直接套用到单卡课题。INCAR-SLM 则通过领域微调和确定性 VASPGuard 检查器生成计算参数文件，在作者采用的基准协议中改善了本地小模型表现[28]。该工作可借鉴模型与检查器的职责分工，却不是配方生成已经有效的证明；计算参数评分与新合金性能验证属于不同任务。

因此，本课题定位为已有辅助设计路线内的小模型适配方法改进。数值工具验证配比限制，记录提供观测依据，模型组织需求、候选与操作说明。可用性应与同证据、同工具的合理方案比较，不把只给学生增加工具后的优势写成模型本体能力优势。

### 2.2 知识蒸馏与参数高效适配

知识蒸馏通过教师监督向更便于部署的学生传递任务能力[7]。Distilling Step-by-Step 利用额外解释性监督改善小模型学习[8]，Orca 2 强调适合学生能力的策略[9]。这些工作为任务示范设计提供依据，但其通用基准结论不能直接转化为材料任务的预期成绩。

MiniLLM 研究能够访问教师分布时的蒸馏目标[10]。本课题主要通过教师生成的文本示范进行序列级任务蒸馏，不假定可获得全词表概率或内部隐含推理。示范包含简短操作、引用与检查结果，适配使用统一监督微调（SFT）目标，避免把无法访问的白盒蒸馏机制写成 API 能力。

LoRA 与 QLoRA 为降低训练参数量和显存需求提供成熟方法[25][26]。拟以 Qwen3-4B 等许可合适的开放权重稠密模型为预算候选，资源允许时加入8B规模对照；Qwen3-32B 可作为分时本地运行的教师候选[27]。型号不代表其材料质量已经合格，最终选择须结合预实验和授权冻结。开放权重许可与托管 API 合同分别核对，不因底座采用某种开源协议，就认定任意平台的输出都允许蒸馏。

### 2.3 教学数据选择：由难度排序到效用估计

Self-Instruct 展示了生成指令并过滤无效或相似样本的基本流程[11]。DEITA 综合质量、复杂度和多样性[12]，D3 结合难度与可信度等因素[14]，LASER 包含任务分层与专用评分[15]。这些方法并不都要求唯一答案，不能将开放答案空间概括为它们必然失效的条件。更准确的问题是：某些文本似然或单参考指标可能与实际任务质量不一致，需要在具体任务中检验。

LESS 以低秩梯度特征估计教学数据影响[13]，GRAD-MATCH 通过子集梯度匹配研究高效训练[30]。ROSE 使用偏好验证集定义效用，指出仅降低下一词预测损失不一定改善任务表现[16]；DRIFT 从已完成 SFT 的检查点出发，以在策略回答的正确性加权构造归因目标，再选择原数据继续训练[17]。本课题不能把梯度选样、偏好代理或学生错误驱动选样单独称为新思想，也应注意 DRIFT 的训练阶段与本课题预热后选样并不完全相同。

DELIFT 通过上下文示例对其他样本预测的帮助建立成对效用，再结合子模目标选样[18]；GIST 研究低维验证梯度子空间与 LoRA 更新几何[19]。这些方法说明效用表示和选择算法都影响结果。上下文帮助不等于参数训练收益，一阶估计也不等于真实长程收益。本课题拟研究的增量是逐约束收益与副作用表示，以及带来源和预算限制的组合决策，不复述已有矩阵或投影作为独创。

### 2.4 约束副作用、训练保护与知识增强

PCGrad 通过投影处理多任务梯度冲突[22]。OGS 将一般能力锚点保护引入数据选择[20]，GRADE 研究在线样本和更新准入[21]。后二者为近期预印本，本课题把其方法作为近邻，不将其全部效果视为已独立复现。它们使“避免有害更新”成为需要正面对照的已有方向；本课题只能围绕多个域内可核验约束组、阶段级离线组合选择及成本形成有限增量。

MuSC 通过约束拆分与偏好数据构造，并使用 token 级优化改善复杂指令遵循[31]。因此增加约束负例或局部损失本身也不足以独立支撑创新。本课题主线仍是教学子集选择，不同时叠加另一套局部对比训练目标或在线强化学习。

RAG 结合参数知识和外部资料[23]，RAFT 研究训练模型使用相关文档、忽略干扰资料[24]；PICARD 在结构化输出中引入增量合法性约束[29]。本课题借鉴证据使用训练和合法输出控制，但分别检验检索、训练和数值修正的收益。已有论文中的问答、SQL或参数文件成绩不能代替配方辅助任务验证。

## 3 研究内容、研究方案、时间安排

### 3.1 研究内容

研究由三部分衔接：构造证据可追溯且来源隔离的任务示范；以分约束修复收益估计进行预算组合选样；把适配模型接入本地检索和数值检查，形成辅助原型。主要算法贡献集中于第二部分，第一与第三部分分别提供可靠监督和实际任务验证条件。

#### 3.1.1 任务定义与可核验教学构造

将资料组织为“成分—状态—测试—性质—来源”记录，并用轻量任务本体表达元素、比例基准、锁定项、条件、记录标识和主张类型。输入要求中的模糊项保留为未知或请求澄清，明确硬约束经数值可行性检查后执行。若约束冲突，返回可核验冲突项，由使用者决定是否放宽。

教师仅在训练资料上构造需求解析、候选与简短操作示范。先核对来源存在、字段对应、比例和单位，再检查要求与答案是否一致。引用存在不等于原文语义支持；语义未知不自动判成正确。观测支持型示范的性能陈述必须对应具体记录；探索建议型只提出候选和编辑说明，不能把相近材料观测转移为新配方性能。

约束扰动以明确原配方为起点，增加锁定项、允许元素或范围后重新核验答案，不只修改需求文本。负例须注明实际违例向量；若一次比例变化同时破坏锁定与总量，不能称为只违反一项。受控需求是人为构造的教学内容，不伪装成数据中已有真实用户需求，派生数量也不等于独立材料实验数量。

#### 3.1.2 诊断代理与分约束修复收益矩阵

从原训练资料内部另划选样诊断集，与SFT教学池按来源关联组隔离。初版围绕锁定项、总量／范围及明确单位换算等少数可靠组构造正负对。条件或语义对应只有在标签依据充分时才加入。诊断集反复用于选样，是训练反馈；开发集负责超参，测试集只用于冻结后的最终评价。

设πθ为学生，x为输入，y⁺与y⁻分别为同输入下已核验的正负答案。诊断采用固定结构的候选、单位、条件和引用字段，不加入自由扩写解释。以长度归一化对数概率构造对比代理：

sθ(x,y)=log πθ(y∣x)/T(y)；L_j(θ)=组内来源均衡平均 softplus(−[sθ(x,y⁺)−sθ(x,y⁻)])。　（1）

其中T(y)为助手答案token数，聚合先按基础任务再按来源，避免同一论文派生题过多而支配代理。每组用开发阶段固定的正尺度a_j归一化，记L̄_j=L_j/a_j；阶段间不随结果任意重缩放。该代理用于计算梯度，不是标准DPO效果保证，也不等于离散错误率。长度归一化不能消除全部模板偏差，需要单独检查代理与真实任务变化是否一致。

在选样检查点r，固定模型θ_r、共同局部步长η和线性映射M_r。教学样本i使用实际SFT损失ℓ_i，其梯度g_i=∇ℓ_i(θ_r)；诊断组梯度h_j=∇L̄_j(θ_r)。仅对LoRA可训练参数计算所需梯度，得到预测收益矩阵：

A_ij=η h_jᵀ M_r g_i；Δ̂_j(S)=Σ_{i∈S}A_ij/k。　（2）

这里k是固定教学子集S的样本数，不是显卡微批大小。正值表示沿冻结方向预计降低该组代理损失，负值表示可能产生副作用。实际损失采用与矩阵一致的逐样本平均；若改用token加权，聚合式同步重定义。初版以M_r=I为清晰起点，低维投影或其他映射作为扩展并计入误差和成本。

式（2）依据一步Taylor近似：L̄_j(θ_r−ηM_rg_S)≈L̄_j(θ_r)−Δ̂_j(S)，其中g_S为选中样本的平均梯度。它是一阶可加模型，不建模任意二阶样本协同。“组合”指多个约束组贡献的联合取舍，不代表已经精确捕获样本相互作用，更不承诺多步训练保护。

#### 3.1.3 带固定参照保护的预算组合选样

设c_i为统一分词、模板和截断后输入与目标输出的非padding token总长度，q_i为质量准入标记。检索上下文计入输入，不能作为免费计算。固定子集规模k与数据长度上限B，在质量、来源集中上限及Σc_i≤B的条件内选样。这个长度上限不是实际GPU成本；监督token、重复轮次、padding、反向计算和选样耗时另记。

在一次选择内冻结薄弱组集合W与受保护组P，固定初始参照θ₀及容差ε_p，拟求：

最大化 t；使 Δ̂_j(S)≥t（j∈W），且 L̄_p(θ_r)−Δ̂_p(S)≤L̄_p(θ₀)+ε_p（p∈P）。　（3）

式（3）还受|S|=k、质量和预算限制。只有最小预测收益达到预定正门槛的候选才接受进一步检查。参考模型、诊断尺度与容差在扩展刷新中保持固定，避免“每次允许退一点”导致累计退化被掩盖。W或P为空、标签覆盖不足等异常按预定协议报告，不默认为满足保护。

首版采用候选窗口内的贪心构造、双样本前瞻及受限交换，保留少量有希望的部分解，形成完整子集后核验全部限制。部分解统一按最终k归一化，只是搜索状态，不是真实更新；不能用其变化中的样本数改变收益尺度。不足k或有限搜索未找到候选，称为“搜索未找到可接受子集”，不等同于数学无解。不预先宣称全局最优、次模性或固定近似比。

选定完整S后，累积实际SFT梯度，用真实优化器状态做虚拟一步，检查组代理的实际变化，随后恢复参数、优化器、随机数和其他可变状态。Adam的动量与二阶矩依赖完整组合，不能把单样本Adam步线性相加。虚拟检查若失败，只按预先限定步长和次数重试，不悄悄放松保护；全部失败则不启动该候选的阶段训练，报告失败开销。

通过后进行预定预算的常规SFT。阶段末同时记录真实约束错误与代理变化，保留“局部预测通过但多步训练退化”的运行。初版只做一次离线选样；最多两到三次刷新作为独立扩展，不在每个训练步加入门控，也不同时训练强化学习选样器。零更新和停训不算修复成功，不能因跳过大量更新而直接声称效率提高。

#### 3.1.4 本地知识增强与候选输出

检索以成分与语义相似为起点，保留比例基准、条件与来源标识。与要求不适用的记录可作背景但不能直接支持性能数值；关键字段缺失时标注缺失，不推断材料不可行。教师教学与推理共用来源和条件表示，训练模型区分相关记录与“成分接近但条件不适用”的干扰项。

生成按元素集合、比例份额、引用与说明分步组织。数值工具核验总量、上下界及锁定项；离散精度和舍入容差在开发阶段冻结。修正比例后必须更新说明和支持范围，不能保留原先已经失配的性能主张。数值求解负责确定性约束，模型的增量体现在需求组织、实例利用与候选说明，需要与相同解析结果和数值工具的传统优化方案比较。

原型全部组件在本地运行，包括生成模型、嵌入、检索和检查工具。训练阶段的教师可分时本地运行，或通过允许该用途的服务访问公开或获准数据；部署不依赖教师接口。系统状态可明确表示“可核验冲突”“输入待澄清”“证据不足”和“预算内未找到”，不能相互混用。

### 3.2 研究方案

#### 3.2.1 拟创新点与贡献边界

**拟创新点一：来源关联隔离下的约束扰动与记录绑定教学。** 将资料字段、人工要求、候选操作和主张类型绑定，扰动后重新核验，避免教师示范虽流畅却不能执行或回溯。任务数据构造已有前作[11][31]，本项主张限于配方辅助的可靠教学协议与实例质量改进，分别移除扰动或显式绑定作消融，不把扩增样本量当作独立知识增长。

**拟创新点二：分约束修复收益与副作用约束驱动的教学组合选择。** 在已有梯度效用和保护性选样基础上[13][16][17][20][21]，保留逐约束影响向量，在预算和来源限制内优化薄弱组收益，并限制其他可靠组相对固定参照的预测损失上升。拟分别检验诊断代理、矩阵信息和组合保护的增量。原先“失误＋覆盖−冗余”启发式保留为对照，不与新规则同时充当主方法；不宣称首次防遗忘或真实性能不退化。

**拟创新点三：教学与本地生成共用约束和证据状态的辅助机制。** 将教学中的来源、条件和锁定状态用于检索增强生成与有限修正，研究其是否减少局部数值修正后的说明失配。RAG、结构化解码和修正器都是已有技术[23][24][29]，通过普通检索、生成后过滤、同求解器及分组件消融确认任务化协同收益，不将系统组件数量计为算法创新。

三项构成“可靠教学—效用选样—辅助应用”的研究链。主要算法增量在第二项，其他两项提供监督与任务验证。它们均为拟研究改进，尚非已证实突破；模型品牌、LoRA、量化和私有化本身不另行算作创新。

#### 3.2.2 数据来源、静态审计与先导划分

主线使用Borg等整理的MPEA公开记录[6]。固定CSV版本共1545条记录、630种规范成分和265个DOI；按记录温度字段20—30 ℃、粗工艺CAST且HV为有限数筛选，得到254条记录、233种成分和55个DOI。该子集温度字段实际均为25 ℃；98条机械试验类型缺失，31条有晶粒尺寸，140条同时有YS值。数据没有单列硬度载荷、保载时间或完整文献段落，不能称为完全同条件的室温硬度实测集。

使用既有解析逻辑，把公式相对系数归一化并形成8位小数规范签名。原始相对系数不和为100不是错误；归一化结果为1也不是原始材料组成真实性证明。全资料有20条完整CSV重复行的超额记录，目标子集有1条；目前未因这些统计自动删除数据。对疑似异常和证据矛盾保留原记录、版本和人工核验说明，不以聚类离群标签代替真值。

先在全部记录上对相同非空DOI、规范相同成分连边，取传递闭包，再投影至目标子集。全图得到110个关联组，硬度子集投影为28组，最大含103条目标记录；只在子集内分组会得到38组，说明其他性质记录也可形成间接关联。关联隔离用于控制显式泄漏，不证明实验统计独立。

已完成一个不看性质数值或模型成绩的确定性划分演示：按目标子集记录配额50%／20%／15%／15%分配完整全图关联组，只使用其中目标记录；无目标记录的其余82个组不参加该先导。数据身份和结果如下。

#### 3.2.3 标签构造与数据规模

首版先做锁定、总量／范围和明确单位等受控组。CSV没有真实用户锁定要求、允许元素上限或材料证据支持标签，因此须人为声明要求、核验正例及记录负例操作。教学池127条记录若每条最多派生8个任务，算术上限为1016，不代表已经得到合格、独立或有价值的任务。预实验按数百个合格任务规划，具体数量由质量和来源上限决定，不复制凑数。

例如，原记录Al0.25 Co1 Fe1 Ni1在声明原子比例基准后，可构造Ni必须保持原值的要求；负例减少Ni并补到另一元素，保持总量正确，从而形成明确锁定违例。记录274 MPa可构造0.274 GPa换算正例；把274直接标为GPa是负例。这些是受控诊断，不是发现原文错误，也不是预测新材料性能。正反方向换算、不同数值范围与表达方式需要平衡，以免模型只识别明显模板线索。

诊断区中有18条正YS记录，来自4个DOI和4个关联组，可作为声明条件下的单位换算载体；不因此宣称有18条独立语义样本。T型记录与C型主张不对应时，标签是“不能直接支持”，不是材料主张为假。HV和YS的性质类型与条件分开绑定，不把机械T/C自动解释为HV测试条件。

约两万篇全文库仅作为用户提供的潜在扩展资源，其覆盖、权限、字段与检索质量尚未审计。首版不以其全部文献数为训练规模，也不依赖商业热力学数据库或未落实的数据申请。额外资料只在取得授权并经同样分区审计后扩展，不能为了扩大指令数量把它变成新的大规模抽取课题。

#### 3.2.4 先导验证与算法实施

先导验证分开检查三类假设：诊断标签是否可靠；矩阵能否预测真实短程代理变化；代理变化是否对应离散约束及实际辅助任务改善。先导研究用于为算法设计提供证据，最终论文仍以方法和辅助原型为成果，不以建立通用评测基准为主线。

先在开发阶段固定子集规模k、长度上限B、来源上限、候选窗口、保留部分解数、交换次数、步长序列、尺度a_j、容差ε与收益门槛τ。初版不同时学习任意样本权重。样本不足、W或P无有效标签、搜索或虚拟检查失败都有明确状态；零更新不得计为修复成功。先检查各组是否确有需要处理的取舍，没有发现则不以防副作用作为主要动机。

对每次选样，记录矩阵预测符号与排序，对照完整子集的真实虚拟一步及短程训练变化；使用未按结果挑选的候选、固定随机种子及来源聚合报告不确定性。若估计失效，缩短跨度、修订有依据的代理或否定该候选方法，不以扩大训练掩盖。正式测试前冻结最终方案，不能根据测试表现反复改门槛。

#### 3.2.5 对照、消融与计算公平性

选样主对照包括当前启发式、随机、简单任务均衡及共享诊断信息的ROSE/LESS类效用选择[13][16]；代表性保护近邻优先选择可复现版本的OGS或GRADE[20][21]，资源不足时公开实现范围和差异，不冒称完成全部原实验。全量教学训练作为额外预算参考，不混称严格等预算。

核心消融分别为：相同收益矩阵压成平均分；相同矩阵去掉组保护；相同候选窗口去掉前瞻和交换；同一强基线增加PCGrad[22]；一次离线与有限刷新的区别。GRAD-MATCH提供了梯度子集选择的基础对照思路[30]，但不要求全部候选同时做重型完整复现。应分离表示、求解、更新准入与额外计算的收益，不把新增可靠诊断标签的价值全部归给算法。

各方法共享底座、教学池、质量准入、诊断信息、数据划分、候选资格和事先限定的调参机会。分别比较相同子集数量与长度上限、实际监督token，以及端到端耗时；输入上下文、padding、重复轮次、梯度提取、虚拟检查、失败重试与教师调用均记录。停训或未找到子集不能通过只汇报少量成功步骤形成虚假效率优势。

系统层面保留本地底座、普通RAG、常规任务蒸馏及完整系统。另加入“相同需求解析结果＋相同检索资料＋传统约束优化器”的强对照，允许其暖启动和候选复用。数值投影与取整是工具收益，不全部归给模型学习。教师比较采用固定版本、提示与预算，在同证据同工具条件下比较系统效果，再单列无工具表现；不依靠文本风格相似认定能力迁移。

#### 3.2.6 评价指标与应用价值验证

记录支持型主任务采用需求级“约束及记录对应双合格率”。任务资格在模型运行前由冻结协议确定：输入完备、数值要求可行，且资料中存在规定数量的不同可支持候选。不能按某个方法是否成功检索或输出调整分母；资格不确定者单列，报告全部纳入和排除数量。

在固定候选数和总生成预算下，候选须满足明确硬约束，规范成分及性质陈述对应适用记录，单位、条件、来源及主张类型一致。字段级对应可自动核验，涉及完整文献语义时仍须可信标注或人工复核；没有标注时只报告记录级指标，不称为完整语义正确。与教师共同使用同一任务集合，报告逐组错误、最差组、多样性、修正和重试次数，不能靠大量采样提升主分而不计成本。

探索编辑任务单独报告约束执行率、正确保留的原记录依据和未验证性能标识。新配方未匹配观测记录，不等于实验失败，也不能仅凭数值合法计入记录支持型主成功。数值冲突、证据不足与需澄清任务单列，报告冲突解释、可行任务误拒及恰当澄清；有限搜索失败不算证明材料无解。

最终主要结论依据来源留出任务，而不是诊断集损失。多个随机种子、来源组重采样和拆分敏感性用于说明不确定性，不把派生题当成独立实验。组数较少时明确结论只适用于该先导范围，不用单次最好值或统计不显著证明等效。与教师的任务质量差值和区间如实报告；“接近”只有在开发阶段预定的实际容许差距及最低可用水平同时满足时才使用，否则只陈述差距。

应用价值首先看在相同资料、预算与工具下，系统是否增加可复核候选、减少无效重试和字段修正。人工时间收益另需任务试用；若获得材料研究者参与，可开展有限案例并报告人数、背景和顺序控制，不设未经依据的最低人数，也不把缺少外部人员包装为已有产业验证。记录级自动指标不能证明合成成功或替代领域研究者。

#### 3.2.7 技术路线、资源与风险

技术路线为：固定资料与来源关联审计→教学池、诊断、开发、测试隔离→教师示范与受控标签核验→冻结检查点提取逐组收益矩阵→预算组合选择及虚拟一步检查→QLoRA阶段适配→本地检索、生成与数值复核→强对照、来源留出和成本分析。图3-1展示训练与部署的职责边界。

资源沿用单张约32 GB显卡起步、必要时48—60 GB租用、约64 GB内存和足够固态存储的规划。输入长度与微批在预实验中确定，不把某型号的最小显存当作完整流程保证。只提取LoRA参数梯度，分批缓存所需特征，不存全参数Hessian，不引入专家集成或强化学习选择器。教师示范可分时生成，避免同时常驻教师与学生增加显存。

风险首先来自资料量和标签范围：受控数值组可构造，完整语义监督尚缺；四区静态示例可行，来源留出统计仍有限。其次是代理失配与矩阵过时：局部近似通过不保证多步效果，必须保留退化运行。第三是成本：复杂选择若没有相对简单方案的任务或效率增量，就不应作为主要贡献。第四是工具掩盖模型错误：应分别报告修正前后及同工具基线，不以同一评分器训练与评价的闭环证明材料科学正确性。

#### 3.2.8 预期成果与研究边界

预期形成可追溯任务规范及来源隔离清单、分约束收益估计与预算组合选样方法、轻量适配权重，以及本地候选辅助原型。成果同时包括对照、消融、成本和失败分析，不仅是界面或一个模型文件。

已有工作是文献核查、数据字段统计和静态关联划分示例；教学集构造、梯度效用、阶段微调、原型及试用均尚未实施。若方法增量不足或模型未达到可用水平，如实收紧结论，不以本地化代替验证。学位是否达标仍由所在单位依据其规范判断，本报告不提供完成保证。

公开数据保留版本与许可，教师服务条款须允许相应用途；内部配方的上传、训练和公开分别取得授权。部署核查生成、向量化、重排和工具的外发行为。报告由AI辅助检索、写作和一致性复核，不声称系统性全量查新或逐篇复现实验。涉及人员试用时按单位要求保护知情同意与数据，作者、经费、利益冲突及个人信息由实际研究者填写。

### 3.3 时间安排

按正式启动后八个月规划，保留相对月份，具体学籍及答辩日期由研究者填写。

第1个月：核定任务、许可、来源关联规则与字段范围；检查诊断标签，冻结先导数据身份与元数据划分，记录实际任务量。

第2个月：构造并抽查教师示范、受控正负对和干扰资料；完成底座、普通检索与常规任务蒸馏基线，测量资源预算。

第3—4个月：完成分约束收益矩阵与有限组合选择；先核验一步预测，再开展阶段适配；对照聚合效用、组保护、求解与成本，冻结最终方案。

第5个月：集成本地检索、分步候选生成和数值复核，完成同工具强对照及组件消融，确认记录支持型与探索型输出边界。

第6个月：完成来源留出、未见约束组合及教师比较，汇总真实任务指标、不确定性、失败与总成本；有条件时进行有限案例试用。

第7—8个月：整理复现材料、论文和局限性，完成修改及答辩准备。资源不足时缩减额外模型、刷新和外部扩展，不删除证明核心增量所需的公平对照。
