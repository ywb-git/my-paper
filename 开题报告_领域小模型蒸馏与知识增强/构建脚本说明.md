# 构建脚本说明

## 用途

`build_report.py` 把 `开题报告_正文.md` 渲染成符合北京科技大学开题报告格式的 Word 文档。

格式基准取自同目录的两份范本：
- `开题报告-唐宁俊V3.docx`
- `开题报告-李壮壮V1.3.docx`

## 用法

```bash
# 1. 生成 Word（目录用 TOC 域，Word 打开后自动提示更新）
#    默认输出：开题报告_格式版.docx
../.venv-docx/bin/python build_report.py

# 2. 生成静态目录版（用于转 PDF，因为 LibreOffice 不计算域）
#    默认输出：开题报告_格式版_静态目录.docx
../.venv-docx/bin/python build_report.py --static-toc

# 3. 指定输入输出
../.venv-docx/bin/python build_report.py 某正文.md 某输出.docx

# 4. 覆盖已存在的输出文件（默认会拒绝）
../.venv-docx/bin/python build_report.py --force
```

**两种模式的默认输出文件名不同**（`开题报告_格式版.docx` vs `开题报告_格式版_静态目录.docx`），不会互相覆盖。若目标已存在且未加 `--force`，脚本提示后以退出码 2 退出。

**运行自检**：

```bash
../.venv-docx/bin/python -m unittest -v test_build_report.py
```

19 个用例覆盖解析器边界、章节拆分、格式不变量、引用编号连续性、表格空 run、封面留空等。

## Markdown 约定

脚本按以下规则解析正文：

| Markdown | 渲染为 |
|---|---|
| `# 标题` | 文档题目（只用于封面，不输出到正文） |
| `## 一级` | Heading 1（章） |
| `### 二级` | Heading 2（节） |
| `#### 三级` | Heading 3（小节） |
| `**粗体**` | 加粗 |
| `[1]` `[2]` | **上标**（学术引用惯例） |
| `{{FIG41}}` 或 `{{FIG31}}` | 插入技术路线图 + 图题 |
| `\| a \| b \|` 表格 | 转成 Word 表格 |
| `## 参考文献` | 其后每行 `[n] ...` 解析为参考文献条目 |

## 目录的两种模式

**TOC 域模式（默认）**
- 插入 Word 目录域，`updateFields=true`
- Word 打开时会提示「此文档包含的域可能引用其他文件，是否更新？」
- 选「是」即生成带页码的真实目录
- 优点：页码自动、可点击跳转

**静态目录模式（`--static-toc`）**
- 直接写入标题文字，不含页码
- 用于 LibreOffice 转 PDF（它不计算域）
- 优点：PDF 里能看到目录

**建议流程**：Word 版用默认模式（在 Word 里更新域），PDF 版用 `--static-toc` 生成后转换。

## 注意事项

**1. 个人信息全部留空。** 封面六项信息与日期均为下划线占位，需手填。

**2. 章节结构需与范本对齐。** 范本是三章结构；当前正文有六章（多了「拟创新点」「可行性」独立成章）。脚本按 Markdown 标题原样输出，不会自动合并章节。若要严格对齐范本，需先调整 md 的章号。

**3. 图题编号默认写死为「图 4-1　技术路线图」**，可通过脚本顶部 `DEFAULT_FIG_CAPTION` 常量修改。若章节调整导致编号变化，需同步改这个常量。

**3.1 表格各行必须有相同的列数。** 列数不一致时会自动补齐空单元格（多出的列会截断）并打印警告，不会静默丢行。看到警告应回头修 Markdown。

**4. 数学公式原样输出。** `$...$` 与 `$$...$$` 都不做渲染，会以源码形式出现在 Word 里。当前正文有意保留了少量公式源码，如需正式排版应改用 Word 公式编辑器或转成图片。

**4.1 未识别的占位符会告警。** 除 `{{FIG31}}` / `{{FIG41}}` / `{{FIG}}` 外的 `{{XXX}}` 会按普通文本输出并打印警告。

**5. 依赖与版本。** 需要 **Python >= 3.10**（脚本用了 `X | None` 类型标注），依赖 **python-docx >= 1.0**。使用 `/home/yin/study/KaiTi/.venv-docx/bin/python`（python-docx 1.2.0）。系统 python 若无 python-docx 会报错。
