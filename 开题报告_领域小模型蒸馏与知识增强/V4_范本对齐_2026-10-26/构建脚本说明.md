## 目录与两遍构建（交付必读）

Word 的目录是「域」，未更新时显示的是缓存结果。若缓存只写提示文字，交付件在不会自动更新域的阅览器里就是一句「请更新域」，与范本（带页码的目录）不一致。因此**正式交付件必须用两遍构建**：

    /home/yin/study/KaiTi/.venv-docx/bin/python build_deliverable.py

流程：第一遍用占位目录构建并转 PDF → 用 pdftotext 定位正文首段与各标题所在页 → 算出正文页号（正文节从 1 起算）→ 第二遍把（标题, 页码）写进 TOC 域的**缓存结果** → 页码稳定即停（最多 3 遍）。域本身保留，在 Word/WPS 里仍可按 F9 重算；另写入 `w:updateFields`，打开时也会提示更新。

当前结果：总 **17 页**，正文起于 PDF 第 3 页，目录 **22/22 条带页码**，两遍页码一致。依赖 soffice、pdfinfo、pdftotext。

静态目录模式（`--static-toc`）无页码、不写域，仅用于无域环境的阅览。

## 针对性验收

- 正文引用集合与 43 条书目双向对应，逐条题名匹配本轮 API 返回标题，编号闭合不替代来源核查。
- Word 文献书签实际包住 [n] 编号，REF 域数量与引用相关，不能只查书签存在。
- 公式以 `m:oMath` 计数核验（当前 10 个），并核验右端编号连续；仅检查「有文字」不能证明是公式对象。
- 嵌入图片字节与当前 PNG 的 SHA-256 一致，图题与正文对应，并附图片替代文本（descr）。
- HTML 通过标签、锚点与本地文件链接检查，Chrome 直接打开 file URL 检查桌面和窄屏；不启动新的 DSH 或 Web 服务。
- 封面学校、指导教师、单位、姓名、学号、专业、入学时间、填报日期均留空；计划使用相对月份。
