# 面向材料文献问答的条件可比 RAG 与小模型蒸馏方法研究

## 1 选题背景及选题意义

### 1.1 选题背景

材料文献为配方与实验方案准备提供重要依据，但文献中的性能数值通常附属于特定成分、样品状态与测试条件。一次查询得到主题相关的材料，并不意味着能够直接据此回答问题。以合金性能为例，同一成分在不同工艺或测试温度下的记录都可能被检索到；若回答只保留数值而丢失限定条件，就可能形成带有真实引用、却不支持当前主张的结论。

大语言模型已经进入材料辅助研究。LLMatDesign 将自然语言理解、材料修改和工具评价组成迭代流程[1]，针对 BCC/B2 合金的偏好学习研究表明，开源模型可经任务适配提出候选成分[2]。LLaMat、AlloyGPT 分别从领域适配和结构化建模角度探索材料模型[3][4]，AlloyLens 则体现了文献与数据筛选、比较和交互分析的应用价值[5]。这些工作为本课题提供基础，但其生成、预测或筛选成绩不能直接证明本地小模型已能可靠使用材料文献。

本课题保留“小模型、检索增强生成与蒸馏”的方向，把研究对象放在材料文献问答的两处工程决策：第一，在有限上下文预算下，哪些测量记录应以何种粒度进入模型，并保留哪些必要条件；第二，面对抽取结果中的疑点，有限核验时间应优先投入哪些共享字段或记录。两处决策共同影响进入模型的信息质量，但分别位于上下文装配与知识库维护阶段，应分开建模并检验增量。

### 1.2 选题意义

应用层面，本课题辅助文献查证与方案准备。研究者需要的不只是一个可能正确的数值，还包括它属于哪条测量记录、适用于何种条件、引用能否回到原文。小模型可在本地组织资料并生成解释，降低资料反复查找与整理的操作负担。系统拟交付有条件依据的回答及多步查询能力，不把提升真实合成成功率或缩短全部材料研发周期作为未经验证的承诺。

方法层面，本课题联合处理证据价值、条件完整性与预算。常规片段排序不能保证性能数值与表头、表注或工艺说明一同保留；保留完整论文又可能挤占小模型上下文。提示压缩已有成熟基础[6]，背包式上下文选择也已有前作[7]。本课题拟在这些基础上显式表示记录依赖，联合选择记录版本和必需条件，并计算共享字段的实际装配成本，而不是只改变检索相似度或追加输出格式要求。

知识库维护层面，由逐条排队改为按影响选择核验动作。同一表注的温度抽错可能影响多条性能记录，逐条查看的成本与核验一次共享字段不同。已有研究提示抽取数据库需要核查[8][9]，抽取置信度与复核预算也已有专门研究[10]。本课题拟将记录级疑点、共享依赖和预计核验收益联系起来，用有限预算优先处理影响范围较大的疑点，再通过独立抽检估计误放行。

部署层面，形成可保存和可复现的本地工具。生成模型、嵌入、索引与检查组件在部署时均可在本地运行，保留资料与模型版本。该优势不等于本地一定比云端便宜，也不代替模型质量检验。研究重点仍是可运行方法：装配器、核验调度器和适配小模型共同接入一个可追溯的 RAG 系统；对照和误差分析只用于验证这些方法，不作为课题最终产出的替代品。

## 2 文献综述

### 2.1 材料领域模型与条件可比问答

材料领域模型已有不同技术路线。LLaMat 研究大规模领域适配[3]；AlloyGPT 将组成与性质组织为结构化文本[4]；LLMatDesign 和 BCC/B2 偏好生成研究把模型与外部评价结合[1][2]。这些研究支持借用开放权重和任务适配，但不要求本课题复现通用材料基础模型预训练或购买商业热力学资源。MaterEval 通过知识增强偏好信号研究材料判断[11]，说明教师与评价器也需要领域依据，不宜把模型认同当作材料事实。

材料文献记录的数据结构直接影响后续使用。MPEA 提供成分、工艺、机械性质与来源字段，是本课题可取得的结构化主线资源[12]；真实论文补充库则需要解析、字段绑定与人工核验。INCAR-SLM 展示了领域微调与确定性参数检查器的分工[13]，但其计算参数文件任务与材料观测支持型问答不同，不能移用其分数或模型规模结论。

本课题的基本对象是可追溯的测量记录，而不是可随意互换的主题片段。条件不同的记录仍可以用于比较或背景说明，但不能在未说明的情况下转为同一条件下的观测。测试温度接近只表示数值距离小，不能直接证明性质等价；相同粗工艺标签也不能保证热处理、晶粒或测试细节完全相同。

### 2.2 小模型蒸馏与参数高效适配

知识蒸馏通过教师监督向更便于部署的学生传递任务能力[14]。Distilling Step-by-Step 与 Orca 2 分别探索额外操作说明和适合小模型的解题策略[15][16]，MiniLLM 讨论可访问教师分布时的优化[17]。本课题主要使用教师文本示范进行序列级任务蒸馏，不假定可以取得全词表概率或教师内部隐含推理；教师示范含简短操作、来源与限制说明，科学事实仍需记录和人工依据支撑。

Self-Instruct 提供生成并过滤指令的基本思路[18]。DEITA、LESS、D3 与 LASER 分别研究质量复杂度、梯度影响、多因素选择及分层专用评分[19][20][21][22]。这些方法并非都以唯一答案为前提，不能笼统认定其在开放答案任务上失效。本课题不再以新教学选样算法为主贡献，而将它们作为构造与筛选示范的相关方法，选样收益不与上下文装配收益混为一谈。

LoRA 与 QLoRA 可降低适配参数量与显存开销[23][24]。拟采用 Qwen3 等许可合适的 4 至 8B 级稠密底座[25]，版本、上下文长度与训练预算在预实验后固定。基础模型许可与教师服务条款分别核验；不能因为权重可取得，就认定任意托管服务的输出都允许用于蒸馏。

### 2.3 检索增强、条件组织与证据压缩

RAG 将生成模型与外部资料结合[26]。RAFT 通过相关资料与干扰资料构造学习证据使用的任务[27]，HalluGuard 研究小模型接地能力[28]，DRAG 研究把大模型 RAG 行为迁移到小模型[29]。这些研究说明训练证据使用能力已有前作，本课题不能把采用 SFT、加入引用或更换为小模型本身称为独创。

OG-RAG 与 EGT-KG 分别利用本体或类型化图结构组织检索信息[30][31]，材料双源 RAG 研究展示了本地文献与结构化资源的整合[32]。CGR 在生物医学问答中以查询条件激活或剪除图路径[33]。知识图谱能够表达条件，不能以“实体关系无法表达实验条件”立论。本课题的拟改动是显式测量记录绑定、版本选择及共享依赖的成本模型，其效果应由相同字段条件下的强基线检验。

LLMLingua 已研究预算控制与提示压缩[6]。Self-Correcting RAG 将上下文选择组织为多维多选择背包问题[7]，其可访问版本将语义分组与预算约束结合。VITAL-RAG 在代码场景中按规范对象组织不同视图，并在对象与全局预算下装配上下文[34]。这些都是多粒度选择的近邻，因此不能把“多版本”或“背包优化”单独作为创新；本课题强调一条测量记录对表头、表注、单位、工艺与来源的依赖闭包，以及在不破坏绑定的前提下复用共享信息。

压缩后的可读性与来源支持并不相同。Attribution–Compression Frontier 对不同压缩方式的自动评估提示，压缩文本内部的引用支持可能与原始来源支持分离[35]；其研究也明确自动判分与人工校准的局限。本课题据此把来源定位和条件保留作为装配约束，但不引用该论文的自动分数充当本课题的预期错误率。

PICARD展示了解码时约束结构合法性的做法[36]。本课题可借鉴结构输出检查，但语法合法不能保证数值、条件和来源相符；装配依赖与回答事实应独立核验。

### 2.4 核验调度与优化基础

MinerU 为文献结构化提供解析入口[37]，Grounded Verification 和 LitMOF 分别从推理核验和材料数据库核查说明检测与来源对照的重要性[8][9]。其特定任务结论不能外推成所有材料记录都存在同样的错误比例。跨记录差异可生成疑点，未经原文和领域判断确认，不能直接标成抽取错误。

ActiveDP 研究主动学习与数据编程的结合[38]，ConfBench 研究文档抽取置信度、校准和复核预算指标[10]。这些工作说明弱标签、置信度筛选与有限人工预算已有方法基础；本课题拟改变的是核验对象与影响关系：由单条记录转为可能影响多条记录的共享文献字段和复核动作，不主张首次主动核验。

覆盖型集合优化具有成熟理论。Nemhauser 等给出特定基数约束下单调子模最大化的经典结果[39]；S-RAG 将查询相关概念的加权覆盖用于 token 背包式上下文选择[40]，所读 OpenReview 页面为投稿版本，不能写成已确认录用。标准覆盖目标可以作为本题代理，但加上版本互斥、共享依赖和实际预算后，不能直接沿用简单基数贪心的近似比。本课题将求解器与目标区分，数值检查只核验实现，不能替代数学证明或回答正确率验证。

### 2.5 相关算法原理

前三节给出与本题相邻的工作与边界，本节把后续直接使用的四组算法原理单独写出，说明本课题的公式与实验设计各自借用了哪一部分标准结论，以及在哪一步改变了问题形态。

#### 2.5.1 覆盖型集合选择与预算约束

加权最大覆盖问题给定元素集合 U、可选集合族 S 与权重 w_j，选择至多 k 个集合使被覆盖元素权重之和最大，其目标函数单调且具有边际收益递减性，因此基数约束下的贪心解具有 1−1/e 的近似保证[39]。当每个可选对象带有成本、总成本受预算 B 约束时，问题变为预算最大覆盖，贪心按边际收益与成本之比排序不再保持同一近似比，需要以整数规划或列生成求参考解。上下文装配与上述形式同构：测量记录是可选集合，可核验事实是被覆盖元素，token 是成本；差别在于同一记录的多个版本互斥、覆盖一个数值时必须同时选入其表头与表注等依赖项，因此可行域比标准形式更紧。求解器的近似比结论不能直接沿用，这是本课题把参考解与部署启发式分开报告的原因。

#### 2.5.2 列表排序与条件对比目标

列表排序把整段候选视为一个样本，用 softmax 形式在候选集合上定义似然，其损失为正确项负对数概率，训练时对候选池内全部候选取和，因此与逐对的 pairwise 合页损失相比更能反映池内相对次序。对比学习在此基础上用锚点与正负例的相对距离构造目标，温度 τ 控制分布尖锐程度，间隔 m 控制正负例的最小间隔。本课题的条件变化一致项属于对比形式的一种变体：锚点不是同一条记录的不同视图，而是同一问题在条件改变前后的正确记录，要求两次评分次序相反。这样可以检验学生是否真的依据条件判别，而不是固定偏好某一条记录；同时也意味着负例必须来自同一候选池、只允许一个条件不同，否则翻转要求本身不成立。

#### 2.5.3 提示压缩与上下文预算分配

提示压缩在信息保留与 token 预算之间取舍：粗粒度方法删除句子或段落，细粒度方法删除词元并保留可复原的压缩表示，预算控制则由目标压缩率或硬性 token 上限给出[6]。背包式上下文选择把每个候选文本块视为带价值与成本的物品，在预算约束下最大化总价值，并以语义分组或冗余折扣避免重复[7][34]。两类方法的共同前提是“块的价值可加”，而材料测量记录不满足该前提：一个数值离开其表头或表注即失去支持资格，共享依赖还会产生一次写入、多处引用的成本结构。本课题因此把可加价值改为带硬准入标记的覆盖目标，并把共享依赖的 token 计入总成本，而不是各自单独计费。

#### 2.5.4 约束感知解码与结构校验

约束感知解码在生成过程中对词表施加自动机或文法约束，使输出始终满足结构合法性，从而避免后处理修补[36]。这类方法保证的是形式合法，不保证内容为真：一个符合语法与字段格式的数值仍可能来自错误条件或错误来源。本课题据此把校验分为两层——生成侧只借用结构检查保证可解析，事实侧依靠装配依赖、来源定位与条件对应独立核验，两层结论分别报告，不以“格式正确”代替“事实正确”。

## 3 研究内容、研究方案、时间安排

### 3.1 研究内容

研究以提升小模型材料文献问答的正确率为目标，包含两项拟方法改进和两项支撑工作。第一项为条件依赖闭包下的多粒度证据装配，解决“记录选进上下文但条件被压掉”的问题；第二项为下游影响驱动的核验调度，解决“有限人工时间按记录逐条分配效率低”的问题。支撑工作是基于完整证据包的小模型蒸馏，以及多步 Agent 原型。主要交付物是可运行模块和系统，不以构建通用基准或输出失效分析报告为课题定位。

#### 3.1.1 条件依赖闭包下的多粒度证据装配

针对性能数值、单位、温度、工艺与来源分散在表格、表注与正文的问题，把测量记录表示为可核验的版本（来源原片段、条件绑定摘录或紧凑记录卡），每个版本携带依赖闭包，覆盖解释该数值必需的表头、单位、工艺与来源字段，并按文献、表格、样品与性质标识绑定，不按相同字符串跨记录推断。对固定查询，把需回答的内容拆为若干项测量事实，用式（1）计算版本对事实的支持效用，并区分“必要条件已知冲突或来源无法对应”与“评分较低”两种情形：前者不具备直接支持资格，后者仍可参与比较。在式（1）之上，用式（2）至（4）联合选择记录版本与必需依赖，其中式（2）使同一事实不被重复累加，式（3）保证选入数值时同时选入其必要条件并限制同一记录只取一个版本，式（4）允许共享依赖按实际 token 成本摊销。求解先以小候选池的整数规划或穷举作参考解，部署时以边际效用除以新增闭包成本构造候选并作有限替换，限时求解必须报告可行解、上界与缺口，不能把超时解称为最优；块成本仅是规划口径，最终上下文用真实分词器复算，超预算时退回较短的合法版本而不是从尾部截断条件。加权最大覆盖的单调性与边际收益递减性属已有结论，本课题不据此主张新定理；拟增量是记录粒度、依赖关系与成本的联合计算，须以同字段强基线和分项消融证明。

#### 3.1.2 下游影响驱动的核验调度

针对全文抽取结果中既有单行错误、也有共享表头与表注错误的问题，把核验对象由单条记录改为可影响多条记录的共享字段与核验动作：核验动作定义为查看特定来源位置、核对明确字段及其影响范围，不把“重新运行整个模型”与一次人工查看混为同成本动作。令 p_i 为记录有误的估计、v_i 为冻结工作负载下的下游影响权重、r_ai 为动作对处理该疑点的预计帮助、t_a 为动作时间，用式（5）选择动作集合、式（6）约束总核验时间；式（5）按共享依赖传播作用范围，并用最大帮助避免同一疑点被重复计功。参数来源须分开报告：p_i 由训练资料内的人工核验记录与抽取特征估计并在开发集校准，置信度不能直接当真值；v_i 来自预先指定的查询类型与依赖关系，不使用测试题答案反向调度；t_a 由真实计时估计，先导资料缺失时只报告计划而不给出节省比例。用边际收益与时间成本比构造动作队列并作有限交换，核验后更新已知字段与未决疑点。为避免只评估被选中的样本，总预算中预留独立抽检，随机抽取自动通过与低优先级记录，按抽样概率估计误放行并报告区间；核验动作须同时报告“发现问题”与“确认修复”，不以疑点数冒充检出真错。

#### 3.1.3 条件变化一致的证据使用联合蒸馏

针对“学生只学会引用某条记录、而非判断哪条记录适用于当前条件”的失效，训练目标在答案监督之外加入候选池列表排序与条件变化一致两项。设 s_θ(q,d) 为学生重排头对问题 q 与记录 d 的评分、D(q) 为固定候选池、d⁺ 与 d⁻ 分别为适用与不适用的记录，按式（7）组合三项损失：式（8）为完整证据包上的答案监督，式（9）为候选池上的列表排序，式（10）由两个方向组成，要求 q 与 q′ 只在一个条件上不同时学生的偏好随之翻转。与已有检索器蒸馏的判别点在于：已有工作要求学生复现教师的证据排序，本项要求排序随条件改变而相应改变；若新条件下没有对应证据，学生的正确行为是识别证据不足，而不是沿用旧记录或强行作答。实现须在开题阶段固定的细节包括：s_θ 是实现为独立 LoRA 重排头还是生成模型内部的结构化排序输出，候选池是否固定，负例从同成分其他条件记录还是从全局随机采样，τ、m、λ_r、λ_c 在开发集如何冻结，以及排序损失与答案损失的样本和 token 预算配比。消融设五组：仅答案 SFT、加普通排序蒸馏、加条件一致损失、完整目标、逐项去掉温度或工艺或试验类型之一，第五组用于判断哪类条件最难学。

$$L=L_{\mathrm{SFT}}+\lambda_{r}L_{\mathrm{rank}}+\lambda_{c}L_{\mathrm{cond}}$$

$$L_{\mathrm{SFT}}(\theta)=-\sum_{(q,E,y)}\sum_{t}\log\pi_{\theta}(y_{t}\mid q,E,y_{<t})$$

$$L_{\mathrm{rank}}=-\log\frac{\exp\left(s_{\theta}(q,d^{+})/\tau\right)}{\sum_{d\in D(q)}\exp\left(s_{\theta}(q,d)/\tau\right)}$$

$$L_{\mathrm{cond}}=\max\left(0,m-s_{\theta}(q,d^{+})+s_{\theta}(q,d'^{+})\right)+\max\left(0,m-s_{\theta}(q',d'^{+})+s_{\theta}(q',d^{+})\right)$$

#### 3.1.4 本地 RAG 与多步 Agent 验证载体

原型整合资料管理、核验调度、检索、证据装配与小模型回答。主任务用单轮问答验证；多步 Agent 检验条件补充后的重新查询与预算受限下的证据更新，固定查询、条件核对、证据装配、澄清和终止等动作，预设最大轮次与总 token 预算，不得未经用户同意修改其目标成分、工艺或容许范围，也不将执行器本身另算算法创新。逐轮保存问题条件、候选记录、版本与依赖、装配成本、模型引用和动作依据；用户补充要求后重新计算资格与证据包，不沿用已经失配的旧答案。模型、嵌入和索引本地运行，资料版本、分词器与工具版本可冻结；最终交付可运行方法与原型，评价仅服务于验证这些方法。

### 3.2 研究方案

研究方案按“数据与来源绑定→核验动作定义与下游影响建模→预算核验及独立抽检→版本化知识库→固定检索召回→条件依赖闭包与多粒度装配→经任务蒸馏的小模型回答→多步 Agent 集成与来源留出验证”推进，核验维护与在线回答是两条相接但可独立替换的路径，不把人工核验偷偷放进无成本推理环节。两项方法改进分别对应式（1）至（4）的装配与式（5）（6）的调度，支撑工作对应式（7）至（10）的蒸馏与执行器。

样本构造的可行性已实测。条件变化配对须保证两条记录同时存在且只差一个条件：对主线数据统计，四要素齐全的记录一千二百零五条，同成分且温度不同者二千零一十五对，其中最严格的口径下（工艺与试验类型也相同，即真正只改变温度）为一千三百零三对，该规模足以支撑条件变化的成对训练，且每对可同时提供正例与反例。三点边界须在设计中守住：第一，只有候选池同时包含条件匹配与不匹配的记录时才构造排序翻转，若新条件下没有对应证据，标签为证据不足，不制造虚假正例；第二，温差接近不等于性能可互换，不据此标注任何训练真值；第三，若 q 与 q′ 本可由同一条记录支持，则不强制偏好翻转。

**研究难点。** 第一，依赖抽取错误会使闭包完整却语义绑定错误，结构约束只能防止已识别依赖丢失，不能证明初始抽取正确。第二，支持效用与最终答案表现可能失配，优化目标与主质量须分开报告。第三，共享条件只在确有相同作用范围时省成本，跨表或跨来源不作无依据复用。第四，核验收益参数与人工时间不稳定，需独立抽检和实测校准，不能把低置信样本集合当总体。第五，全文库覆盖、许可与字段可得性尚未核实，未取得原文时不虚报真实抽取与节时。第六，模型可能只学会保守或复制格式，需可回答题误拒与同工具对照；教师输出与检查通过都不是新材料性能证明。

**数据身份、参数估计与公平对照。** 先规范 DOI、完整重复记录、成分与样品标识，再建立来源关联组，至少保证同论文、同记录及其派生版本不跨区，同成分留出作为更严格压力设置；训练、开发与测试按组划分，首个可行划分及构造协议在模型运行前冻结。核验参数、支持评分和教师示范只从训练资料生成，调参与校准使用开发资料，测试参考答案及其人工判定由独立协议保存，不能作为装配效用或调度优先级的输入。装配主对照使用相同召回池、字段和来源：按语义 top-k 后截断、条件字段文本拼接、固定完整条件卡、字段保护的压缩方案、标准预算覆盖或多选择背包方案，以及本课题联合装配；所有方法均可取得条件与必要定位，固定卡同样保留完整条件，避免故意设置会丢字段的弱对照。装配消融依次固定一个粒度而不联合选择、依赖块逐条复制而不共享、移除闭包约束但保留相同字段候选、以相同候选和预算仅用局部贪心，分别检验粒度、共享成本、条件保护和求解的贡献。核验对照包括随机动作、逐条不确定性、只按影响范围、完整预算调度及小批全核验参考，各组真实 H 与独立抽检预算一致；并依次令 v_i 一致、移除共享影响关系、以相同动作只按初始置信度排序，分离影响权重、依赖和更新策略的收益。

**指标与验证方式。** 主指标为来源留出任务上的答案事实正确率，条件敏感查询为主要分析组，一般事实查询为对照；逐项核验数值、性质类型、来源与条件对应，有事实标签的记录级问题可自动判断，开放原文问题需要预先核验参考和人工裁定。答案充分性需区分“某条件下有哪些观测”和“整个区间的性能规律”，离散测量点不自动证明连续区间内性质，不能因为装配覆盖较广就宣称物理充分；无法支持的部分保留缺口说明，不因某系统拒答或检索失败改变主分母，同时报告可回答题误拒与证据不足题恰当说明。装配报告条件依赖保留率、来源绑定错误、最终输入 token、预算违例、装配耗时与端到端答案正确率，目标函数值上升不能替代正确率提升；核验报告每小时实际核验记录、确认真错与修复数量、自动通过区的误放行估计和区间，疑点数不是检出率。多步 Agent 补充报告任务完成度、澄清恰当性、条件更新后的重查、轮数与总成本，固定最大轮数与预算；核心对照采用预定多个随机种子，按来源组配对重采样并作拆分敏感性，组数不足时收紧结论。

**资源与实施可行性。** 按单张约 32 GB 显卡、64 GB 内存和足够固态存储起步，必要时使用获准租用资源，底座、输入长度与微批由预实验吞吐决定；先用固定小候选池与少量表示版本测算法，不同时增加强化学习选择器、大型图谱或性能代理模型。教学与校准可从结构化公开记录开始，但真实依赖抽取和调度收益需要原文与核验资料，先完成可用样本审计再定批量。所有成本包括解析、依赖抽取、预处理、教师、人工核验、训练、装配和推理，报告一次性与每次查询开销；若装配时间抵消质量优势，应缩减候选与算法，而不是隐去时间成本。

**预期成果与完成标准。** 预期成果包括条件依赖及记录版本规范、预算装配方法、影响驱动核验调度方法、任务适配权重、本地 RAG 与多步 Agent 原型及可复现配置。目前已完成文献查证和公开 CSV 静态审计，尚未实现上述优化模块、构造完整教学集、训练本题模型或验证方法增量；主张只写为拟研究改进，不将先前对旧覆盖函数的随机检验和小实例最优比例转移成新方法结果，若实际增量不足则修改方法或收紧结论。

**数据管理、授权与研究诚信。** 公共资源保留许可与版本，内部资料的上传、训练和公开分别授权，教师用途须符合服务条款；部署核查生成、嵌入、检索及工具的联网行为。参考文献逐条按原始出处核对，区分正式出版与所引预印本、投稿版本，不凭记忆补发表信息；可访问元数据不等于逐篇复现实验。报告使用 AI 辅助检索、写作和一致性检查，本轮没有开启子代理、训练模型或进行材料实验；姓名、导师、学校、专业、学号、日期与作者声明由研究者实际填写。

第7个月　完成来源留出、教师比较与多步验证，记录实际成本与不确定性，有条件时开展有限应用案例；
