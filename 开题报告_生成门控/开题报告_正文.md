# 面向晶体结构生成的机器学习势门控与分层决策系统

## 1 选题背景及选题意义

### 1.1 选题背景

材料研发的瓶颈正在从"能否预测"转向"能否筛选"。生成式模型已经能够批量产出晶体结构，MatterGen、CrystaLLM、FlowMM 等开源实现使这一能力不再局限于少数团队。然而，生成本身只是起点：扩散模型产出的候选中有相当比例在物理上不合理、在热力学上不稳定、或根本无法合成。真正的成本集中在"判断哪些候选值得进入下一环节"这一筛选动作上。

在国际上，闭环材料发现已被确立为核心范式。美国"材料基因组计划"、欧盟"地平线欧洲"以及我国《"十四五"原材料工业发展规划》均强调以数据与计算加速材料筛选。闭环流程的一般形态是"生成候选—评估性质—反馈优化"，其中性质评估（通常是密度泛函计算）构成主要成本。因此，如何以低成本代理模型对生成结果进行前置筛选，成为降低闭环成本的关键。

当前的主流做法是训练一个性质预测代理模型，在其输出上排序。这一路线在工程上有效，但存在两个结构性局限。其一，代理模型输出的是性质数值或裸分数，不具备概率语义，无法回答"这批候选整体上有多可信"。其二，代理模型只依赖自身的训练数据，无法利用文献中已有的证据；而新生成的候选往往缺乏计算数据，却可能已有类似体系的合成报道。

大语言模型领域的进展提供了另一种思路。Jev 开创的 System One 决策模型范式使模型不再生成自由文本，而是在受约束的答案空间上输出带概率的类型化判断；其开源实现 Laya 仅约四亿参数，可在单卡甚至 CPU 上运行，且在结构上不可能产生文本幻觉。这一范式与"筛选"任务天然契合：筛选本质上是"这个候选是否值得保留"的判断，而非"生成描述"。

本课题据此提出一种筛选架构：在生成器与下游昂贵评估之间插入一道**以机器学习势（Machine-Learning Interatomic Potential，MLIP）为核心的门控**。机器学习势是专为原子结构设计的等变模型，输入即晶体结构本身，无需序列化，可在秒级给出能量与力，进而计算相对凸包的能量——这正是判断"结构是否可能稳定"的标准判据。门控的作用是把生成器产出的海量候选中物理上不可能或不稳定的部分尽早剔除。

在此之上，本课题进一步研究**分层决策**：MLIP 门控给出稳定性判据与不确定性后，由流程层决定该候选是直接淘汰、进入进一步计算、还是升级至商用大模型或人工复核。流程层的判断对象是"这批候选是否值得继续投入"，属于工作流状态的类型化决策，恰是决策模型类工具的设计用途。该架构不追求生成质量的进一步提升，而是研究"如何以可校准、低成本的方式决定生成结果中哪些值得保留"。

### 1.2 选题意义

**方法意义**：现有生成筛选流水线以性质代理模型为核心，其输出为数值而非概率。本课题将筛选问题重新表述为受约束的类型化决策问题，使筛选结果具备概率语义与可校准性。与以高斯过程为代表贝叶斯代理模型的既有工作相比，本课题的差异在于决策模型可融合异质证据（结构描述、文献先验、约束检查），而非仅拟合某一目标性质。

**工程意义**：本课题以形成可用系统为目标。所设计的三段式流水线（生成—判断—决策）各环节模块可替换，生成器可换用 MatterGen、CrystaLLM 或 FlowMM，判断器可换用不同决策模型，云端接口可按可用性替换。系统在单张消费级显卡上即可运行，为资源受限的研究组提供可复用的筛选工具。

**应用意义**：筛选环节直接决定闭环实验的成本。经校准的接受概率可支撑明确的取舍：高置信候选进入计算或实验，低置信候选进入更昂贵的复核通道，从而把有限资源集中在最可能成功的候选上。这一收益可在公开基准上以离线方式量化，无需依赖真实实验。

## 2 文献综述

### 2.1 晶体结构生成方法综述

晶体结构生成的主流方法是扩散模型与流匹配模型。MatterGen 将扩散过程扩展至原子类型、坐标与晶格，实现从化学式到结构或无条件生成，并支持以性质为条件的生成[1]。FlowMM 采用黎曼流匹配框架，在保持对称性的同时生成结构，其后续工作 FlowLLM 将流匹配与大语言模型结合[2]。CrystaLLM 则另辟蹊径，把 CIF 格式视为一种语言，用自回归语言模型逐字符生成，证明晶体结构可以被序列化处理[3]。

语言模型路线的另一分支是微调通用模型生成材料。Gruver 等证明微调后的语言模型可以生成稳定的无机材料文本表示[4]；后续工作引入不变分词与 Wyckoff 表示以改善生成质量[5][6]。这类工作的共同前提是"结构可以表示为文本"，这一前提对本课题至关重要，因为决策模型的输入同样是文本。

生成质量的评测已有统一框架。LeMat-GenBench 提供了晶体生成模型的标准化评测，覆盖有效性、稳定性、新颖性与多样性等维度[7]，使不同生成器的结果可比较，也为筛选环节的效果评估提供了基础指标。

### 2.2 生成结果筛选方法综述

在闭环流程中，生成结果需要经过筛选才能进入昂贵的评估环节。主流做法是训练性质预测代理模型并在其输出上排序。近期工作进一步提出以廉价概率代理模型作为"门控"：在生成器与性质评估之间插入高斯过程采集门控，在固定预算下匹配甚至超过无门控的微调效果，并在三种架构不同的扩散先验（MatterGen、CrystalFlow、ADiT）上验证[8]。该工作同时指出，门控模型无需准确预测性质数值，只需正确**排序**候选，这显著降低了对代理模型的要求。

另一类筛选依据是物理与化学约束。结构合法性检查（原子间距、电荷平衡、元素守恒）与热力学判据（相对凸包能量）被广泛用作过滤器。这类方法可靠但保守：约束只能排除明显错误，无法区分"合法但无价值"与"合法且有价值"。

在不确定性表达方面，材料领域的校准研究主要集中在势函数与性质预测[9][10]。将校准概率引入决策环节的代表工作是 CrystalJev，其用冻结势模型的一次前向传播输出校准概率与保形保证，并据此决定是否升级至更昂贵的计算[11]。该工作证明了校准概率在材料决策中的价值，但其决策对象是"计算精度层级"，而非"生成候选的取舍"。

### 2.3 机器学习势门控与大模型混合推理综述

生成结果的稳定性判据通常由机器学习势给出。MLIP 是专为原子结构训练的等变模型，输入为晶格与原子坐标，输出能量与力，可用于结构弛豫与凸包计算。近年出现的通用势（如 MACE、ORB）在百万级密度泛函数据上预训练，可跨体系迁移，单卡推理即可运行。其局限亦被明确指出：对训练分布外的化学环境存在局部失效风险，系统平均误差可能掩盖稀疏失效。

在流程决策层面，System One 决策模型的核心特征是放弃自由文本生成，改为在受限答案空间上输出概率。Jev 定义了选择型、评分型与是非型三类问题[12]；开源实现 Laya 以约四亿参数的编码器骨干实现该范式，可在 CPU 运行[13]。Geuter 等进一步证明，现有开源指令模型无需额外训练，仅通过读取末位 token 上选项字母的 logits 即可达到接近商业模型的决策性能[14]。

决策模型的校准方向必须实测确定。针对 Laya 的独立复现报告其置信度系统性偏低（signed gap −0.214），单一温度参数即可显著改善校准误差[15]。这说明校准方案不能预设模型过度自信，须由验证集确定。

混合推理方面，以模型级联与路由为代表的工作证明：将简单请求交给廉价本地模型、困难请求升级至昂贵云端模型，可在保持质量的同时大幅降低成本，其关键在于可靠地估计"本地模型是否够用"[16]。这一思想与门控筛选同构：门控的核心正是判断"是否需要更昂贵的处理"。

### 2.4 本课题与现有工作的边界

综合上述文献，本课题与三项最相关工作存在明确区别。

与**代理模型门控**[8] 相比：该工作以高斯过程拟合目标性质（如热容、体模量）作为采集门控，服务于贝叶斯优化；本课题的门控判据是结构稳定性（凸包距离），目标是候选取舍与分层决策，并强调概率校准与多源证据融合。两者使用不同的判据与决策目标，但同属"廉价代理前置筛选"范式，须在同一生成器与同一评测协议下比较，其对照结果本身即构成有价值的实证。

与**以语言模型生成材料**[3][4] 相比：这些工作关注生成质量本身，本课题不改进生成器，而是研究其输出的下游筛选。

与 **CrystalJev**[11] 相比：该工作的决策对象是计算精度层级（前向→弛豫→密度泛函），其各层级共享同一物理真值，可信度具有天然单调序；本课题的决策对象是**生成候选的取舍**，候选之间不存在真值序，且本课题进一步要求门控按化学体系分组校准并融合文献证据。

与**语言模型生成材料**[3][4] 相比：这些工作关注生成质量本身，本课题不改进生成器，而是研究其输出的下游筛选。

## 3 研究内容、研究方案、时间安排

### 3.1 研究内容

本课题以形成可运行的晶体生成筛选系统为目标，研究 MLIP 门控的构造与不确定性校准、以及在此之上的分层决策策略，并在公开基准上量化其相对既有筛选方法的优劣。系统由三个可替换环节组成：生成器产出候选结构；MLIP 门控计算稳定性判据并估计不确定性；分层决策层据此决定淘汰、继续或升级。研究内容围绕后两个环节展开，生成器采用现有开源实现直接使用其官方检查点，不做重新训练。

#### 3.1.1 候选生成与稳定性判据的构建

生成环节直接采用现有开源实现与其官方检查点，不做重新训练。经核实，MatterGen 提供多个已微调的检查点（按化学体系、按目标性质、按能量高于凸包距离等），其微调范式是"加入可条件化的性质嵌入"而非"换材料体系"，且官方未提供 LoRA 支持、单卡训练显存吃紧。因此本课题不将生成器微调作为研究内容，而是按筛选目标选用相应检查点做条件生成，把研究资源集中于门控与决策环节。

稳定性判据由 MLIP 计算。对每个生成结构，用 MLIP 做结构弛豫并计算能量，进而求得该结构相对凸包的距离。这一判据与公开评测基准的稳定性口径一致——LeMat-GenBench 的稳定性与 SUN 指标本身即基于 MLIP 计算的凸包，因此判据与评测不产生口径分歧。

需明确该判据的局限：MLIP 的凸包计算依赖参考相集，参考集不完备会使距离估计偏移；MLIP 本身对训练分布外的化学环境存在局部失效风险，这一点已有工作报告。因此门控输出的不应是"稳定/不稳定"的硬判断，而应是**带不确定性的稳定性估计**，其可靠性须在验证集上分化学体系报告。

#### 3.1.2 MLIP 门控的不确定性校准与证据融合

MLIP 给出的凸包距离是一个连续数值，直接设阈值即成为硬门控，其代价是阈值选择的主观性。本课题将其转化为概率输出：以验证集上的"实际稳定性"为标签，拟合从凸包距离到稳定概率的映射，并对该概率做校准。

校准分两级。第一级为温度缩放或等渗回归，用以校正概率尺度；第二级为保形预测，用以构造接受集合并提供边际覆盖保证。两者目标不同须区分：校准使数值概率可信，保形使集合覆盖可控，后者不保证单条候选的概率区间。评价指标包括期望校准误差、Brier 分数、经验覆盖率与平均集合大小，并要求按化学体系分组报告，避免总体指标掩盖小组劣化。

在此基础上引入证据融合。除 MLIP 判据外，候选还可获得两类辅助证据：一是结构与化学体系的合法性检查（原子间距、电荷平衡、元素守恒），属硬约束，违反即淘汰；二是文献检索证据（相似成分或结构原型是否被报道过），属软证据，仅作先验调整。两类证据与 MLIP 概率的融合方式采用带可靠性的加权，各源权重由验证集学习确定，而非固定赋值。

需要正视一个工程约束：文献证据的获取依赖检索库，其覆盖面有限。对于检索无结果的候选，不能将其解释为"不可行"，只能标记为"无证据"并降低先验强度。这一区分须在系统中显式记录。

#### 3.1.3 分层决策与升级策略

门控的概率输出须转化为具体动作。本课题将动作空间设为三类：淘汰、进入下游计算、升级复核。升级复核包括调用商用大模型接口或转入人工判断。决策规则建模为成本约束下的阈值策略：设淘汰的代价、继续计算的代价、升级复核的代价分别为已知的模拟参数，则最优阈值由最小化期望总代价确定，并对这些参数做敏感性分析。

流程层的类型化判断由决策模型承担，其判断对象是**工作流状态而非晶体结构**。这一界定至关重要：经核实，通用决策模型类工具的上下文长度与预训练分布均不适合直接处理晶体结构（其英文版上下文仅 512 token，而一个百原子晶胞序列化后远超此限；其零样本在专业判断任务上的准确率亦显著偏低）。但用于回答"这批候选的整体质量是否已足以停止生成"、"当前不确定性是否需要外部证据"这类流程问题，则是其设计用途所在。

因此本课题保留决策模型，但限定其职责为**流程调度**，不承担结构判断。该部分的可选性须说明：若实验表明固定阈值策略已足够，则决策模型的增量价值有限，此结果应如实报告。

### 3.2 研究方案

**第一阶段：环境搭建与可行性验证。** 安装生成器与 MLIP，跑通最小流程。需预留时间应对依赖问题：经核实，MatterGen 的依赖锁定 torch 2.2.1 并绑定 CUDA 12.1 与 Python 3.10，且需安装 PyG 的 C 扩展，若租用机器的驱动版本不匹配，环境搭建本身可能耗费数日。若该路线受阻，备选方案为改用依赖更简单的生成器（如基于 nanoGPT 的 CrystaLLM）或直接使用官方检查点做条件生成。

本阶段须完成三项量化验证：其一，在目标硬件上测量生成 100 与 1000 个结构的显存占用与耗时，确认批量上限；其二，测量 MLIP 对单个结构做弛豫并计算能量的耗时，据此估算门控的吞吐；其三，用官方检查点生成的结构跑通稳定性计算全流程，确认判据与评测口径一致。三项均通过方可进入下一阶段。

**第二阶段：门控构建与校准。** 以公开数据库结构构造验证集，计算其凸包距离并标注稳定性，拟合从距离到概率的映射。实施温度缩放或等渗回归，再构造保形预测集。按化学体系分组报告校准质量，识别哪些体系上 MLIP 判据不可靠。

**第三阶段：对照实验。** 在同一生成器、同一候选池、同一标注标准下比较三类门控：无门控（随机保留）、阈值门控（在凸包距离上直接设阈值）、概率校准门控（本课题方案）。若条件允许，另复现高斯过程门控[8] 作为更强的对照。指标包括筛选后的稳定性比例、校准误差、覆盖率、平均集合大小与端到端耗时。

**第四阶段：分层决策与系统集成。** 实现淘汰／继续／升级三类动作的阈值策略，测量成本与准确率的权衡；完成系统集成与使用文档。使用公开基准[7] 评估生成质量，并自行计算筛选前后的稳定性提升与风险—覆盖曲线——需注意该基准评的是生成器而非筛选器，筛选效果的指标须自行补充。

**评测口径说明。** 公开基准的稳定性指标基于 MLIP 计算的凸包，与门控判据同源，这既是优点（口径一致）也是风险（若 MLIP 系统性偏差，门控与评测会同向偏移而无法互相发现）。因此须另用独立来源做交叉检查：抽取少量结构，以更高精度的计算或文献报道的稳定性做外部校验，报告一致率。

## 4 研究的局限性与预期成果

**判据与评测同源的循环风险。** 门控判据与公开评测基准的稳定性指标均基于 MLIP 计算的凸包。若该 MLIP 在特定化学体系上存在系统性偏差，门控会与评测同向偏移，从而在离线指标上呈现出优于实际的改善而无法自我发现。本课题以少量独立校验缓解，但不能完全消除这一循环。

**MLIP 的分布外失效。** 通用势对训练分布外的化学环境存在局部失效风险，且系统平均误差可能掩盖稀疏失效。MLIP 门控因此不适合作为最终裁决，只能作为前置筛选；其误判会同时影响筛选与评测。

**生成器不做改进。** 本课题不微调生成器，直接使用官方检查点。这降低了工程量，但也意味着若生成器本身产出的候选质量过低，门控再好也无法挽救。经核实，官方微调范式是加入性质嵌入而非适配材料体系，且不提供 LoRA 支持、单卡训练显存吃紧，因此该取舍是资源约束下的合理选择而非遗漏。

**公开基准的历史数字不可直接比较。** 该基准的排行榜曾因能量尺度混用而处于重算状态，历史结果暂不可信。本课题的对照须自行在修复后的版本上运行，不与旧榜单数字直接比较。

**决策模型的作用有限。** 决策模型在本系统中的职责是流程调度而非结构判断。若实验表明固定阈值策略已足够，则该模块的增量价值有限；这一可能性在方案设计时已明确，并将如实报告。

**筛选收益为离线结论。** 本课题以公开基准衡量筛选效果，不承诺提升真实合成成功率。若基准本身与实验可行性脱节，则离线收益不能直接推及实际价值。

**预期成果**：一个可运行的晶体生成筛选系统（含 MLIP 门控、概率校准、分层决策与使用文档）；一组在同一评测协议下与无门控、阈值门控及高斯过程门控的对照结果；对"按化学体系分组校准能否改善门控可靠性"这一问题的实证结论。若结论为否定（校准后的门控不如简单阈值），亦作为负结果如实报告并分析原因。
