# 合金数据集调研（2026-10-21）

## 结论先行

合金数据集数量确实很多，但**大多数对本课题不可用**——本课题需要的是「成分 + 状态 + 测试条件 + 来源」四要素齐全的记录，而多数数据集只提供成分与性能两列。

**当前唯一确认可用的是 MPEA**（已下载、已核对）。

ULTERA 虽然规模大得多（2,700 种 HEA / 6,500 条数据 / 540 篇文献），但**官方明确不公开**，只能通过合作申请获取——这不是网络能解决的。

## 二、MPEA 的实际字段（决定可用性）

23 列，关键字段：

```
IDENTIFIER: Reference ID      ← 来源标识（对应 DOI）
FORMULA                       ← 成分
PROPERTY: Microstructure      ← 状态
PROPERTY: Processing method   ← 工艺
PROPERTY: BCC/FCC/other       ← 相结构
PROPERTY: grain size          ← 晶粒尺寸
PROPERTY: HV                  ← 硬度
PROPERTY: Type of test        ← 试验类型
PROPERTY: Test temperature    ← 测试温度
PROPERTY: YS / UTS / Elongation  ← 强度与塑性
```

**这正好覆盖本课题需要的四要素**：成分（FORMULA）、状态（Microstructure / Phase）、测试条件（Test temperature / Type of test）、来源（Reference ID）。

**这是 MPEA 相对其他数据集的核心优势**，也是本课题选它作为主线的依据。

## 三、ULTERA 的真实情况（重要更正）

**先前判断「IP 被限流」是错的。** 经 127.0.0.1:7897 代理出口（IP 变为 134.195.101.195）测试，Zenodo 仍返回 403，返回体明确写：

> Access to this resource has been restricted due to **unusual traffic from your network**.

且 `sandbox.zenodo.org` 返回 200 而 `zenodo.org` / `www.zenodo.org` / `zenodo-rdm.web.cern.ch` 全部 403 —— 说明是 Zenodo 对该网络段的**风控封锁**，与记录无关。

**更关键的是**：查阅 PYQALLOY 官方 README 后发现，ULTERA 数据**本来就不公开**：

> As of February 2024, the database contains around **6,500 property data points of 2,700 HEAs** coming from almost **540 publications**. It is currently the largest database of HEAs in the world, and while **it is not publicly available** we welcome collaborators who would like to use it in their research or contribute to it.

**也就是说**：Zenodo 上的 403 只是表象，即使网络通了也拿不到数据。ULTERA 通过**合作申请**方式提供（`ultera.org` / `contribute.ultera.org` 均返回 200）。

**对开题报告的处置**：不能写成「待核实」，应写成「**不公开，需合作申请，故不纳入当前主线**」。这对课题是加分——说明作者做过调研而非想当然。

**PyQAlloy 仍可用**（GitHub 200），它是数据质控**工具**而非数据，可作为「质量审计」环节的参考实现。

## 四、对本课题的实际影响

MPEA 的已知局限（已在开题报告 §4/§5 写明）：
- 室温拉伸 YS 仅 287 条 / 91 成分 / 76 DOI
- 室温铸态硬度 254 条 / 233 成分 / 55 DOI
- 630 成分中 556 个（88.3%）仅单一 DOI

**这些限制不会因为找到更多数据集而消失**，因为新增数据集的字段结构不同、条件信息完整度不同，混用需要额外对齐工作，且会破坏「来源分组划分」的统计前提。

**因此**：本课题主线仍以 MPEA 为准，其他数据集作为「未来扩展」列出，不作为当前完成前提。

